# DecodeLabs-Internship-Task-3-SQL-Data-Analysis

## Project Overview
This project focuses on using SQL to extract meaningful insights from a sales and order dataset using Microsoft SQL.
The objective is to develop practical SQL skills by querying, filtering, sorting, grouping, and aggregating data to answer business-related questions.

#
## Dataset Description

The dataset contains 1,200 order records and 14 columns.

Key columns include:

- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- TrackingNumber
- ItemsInCart
- Couponcode
- ReferralSource
- TotalPrice

#


## SQL Concepts Applied

The project focuses on the following SQL concepts:

- SELECT – Retrieving specific columns and records.
- WHERE – Filtering records based on conditions.
- ORDER BY – Sorting query results.
- GROUP BY – Grouping records based on common values.
- COUNT () – Counting records.
- SUM () – Calculating totals.
- AVG () – Calculating averages.

#

## Business Questions Explored

1. How many orders are recorded in the dataset?
2. What are the different products available, and how many unique products are there?
3. Retrieve all orders where the OrderStatus is 'Cancelled'.
4. Retrieve orders where the UnitPrice is greater than 500, arranged from the highest to the lowest UnitPrice.
5. How many orders were recorded for each product?
6. What is the total quantity ordered for each product?
7. What is the average UnitPrice for each product?
8. What is the total recorded order value for each payment method?
9. How many orders are associated with each referral source?
10. Which coupon code has the highest total recorded order value?

#
